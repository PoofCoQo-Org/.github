## Small tools. Real problems. Questionable origins.

PoofCoQo is a one-human software workshop creating free and open-source tools for problems that probably shouldn't require another piece of software. Yet, here we are.

Every project starts with a real problem, usually one encountered by the human behind PoofCoQo. What begins as a personal workaround is refined, tested, and eventually released for others who might find it useful.

No grand ambitions. No revolutionary promises. Just software that does what it's supposed to do.

## AI assisted. Human led.

All application code at PoofCoQo is generated using OpenAI Codex.

The ideas, requirements, design decisions, and quality standards are defined and enforced by a human. Every released application is tested in actual use, not just declared functional because it compiled without complaints.

We don't pretend the code is handcrafted, and we don't use AI as an excuse for poor functionality.

The code is generated. The responsibility isn't.

## A few guiding principles

Free and open source. The tools are made to be used, shared, and improved.

Purpose before features. Solve the actual problem before inventing new ones.

Honest about the process. AI-generated code, human-defined direction.

Tested in practice. If we release it, we've used it ourselves.

No unnecessary complexity. A small tool doesn't need to become an entire ecosystem.
